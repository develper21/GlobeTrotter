> 📚 **Documentation Hub**
> documentation folder
>
> Purpose: single place where every human and AI contributor learns what to build, how to build it, and where everything stands.

| File | Purpose | Read When |
|---|---|---|
| [PRD.md](PRD.md) | Product requirements, features & scope | Planning features or scope discussions |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Tech stack, folder structure, data flow | Adding code, understanding the system |
| [RULES.md](RULES.md) | Coding standards & collaboration rules | Before writing any code |
| [DESIGN.md](DESIGN.md) | Visual design system & UI components | Building or reviewing UI |
| [TASKS.md](TASKS.md) | Task breakdown with status tracking | Picking up work, sprint planning |
| [MEMORY.md](MEMORY.md) | Project context, progress & notes | Resuming work, onboarding |

**Order of reading for a new contributor:** PRD → ARCHITECTURE → RULES → DESIGN → TASKS → MEMORY.
